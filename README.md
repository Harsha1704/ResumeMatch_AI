# ResumeMatch AI
## Multimodal Resume–Job Matching & Skill Gap Analysis System

A university-level supervised machine learning and natural language processing application that analyzes a student's resume against a target job description, predicts compatibility (`No Fit`, `Potential Fit`, `Good Fit`), identifies matching and missing skills, calculates experience gaps, and generates structured resume improvement recommendations with verified educational resources.

---

### Key Capabilities & Highlights
- **Strictly Supervised ML (No LLMs / No Generative AI APIs)**: Driven completely by scikit-learn statistical classifiers trained on genuine public datasets.
- **Multimodal Document Ingestion**: Securely parses PDF (`PyMuPDF`), Word (`python-docx`), and plain text (`TXT`) resumes with format-specific layout and metadata extraction.
- **Technical Token Preservation**: Custom regex-based tokenizer safeguards language/framework identifiers (`C++`, `C#`, `.NET`, `Node.js`, `Python`, `SQL`, `Docker`, `CI/CD`).
- **Deterministic Experience & Skill Gap Engine**: $O(N)$ n-gram set hashing against a validated 4,476-skill lexicon, detecting required vs. preferred skills and categorized gaps.
- **Leakage-Safe Dual Evaluation**: Validated under both novel job generalization (Evaluation A) and group-disjoint unseen resume generalization (Evaluation B).
- **Interactive Flask Dashboard**: Modern, responsive Bootstrap 5 interface with Chart.js visualizations, session security, and dynamic analytics.

## Ground Truth Datasets

The application relies strictly on verified public benchmarks:
1. **Primary Labeled Dataset**: [cnamuangtoun/resume-job-description-fit](https://huggingface.co/datasets/cnamuangtoun/resume-job-description-fit)
   - 8,000 real resume–job pairs (`train`: 6,240 pairs; `test`: 1,759 pairs)
   - Labels: `No Fit` (Class 0), `Potential Fit` (Class 1), `Good Fit` (Class 2)
   - Leakage Reality & Architecture: Held-out test set contains 0.0% job description overlap with train (71 unseen jobs) but 99.8% resume overlap.
2. **Secondary Skills Lexicon**: [batuhanmtl/job-skill-set](https://huggingface.co/datasets/batuhanmtl/job-skill-set)
   - 1,067 domain-annotated job postings
   - 4,476 unique extracted skills categorized into technical, cloud, soft skills, and tools.

## Supervised ML Model Summary & Evaluation

Three supervised classifiers were rigorously benchmarked:
1. **Multinomial Logistic Regression** with ElasticNet/L2 regularization (`best_model.joblib`) — **Selected Champion**
2. **Linear Support Vector Classifier** with isotonic probability calibration (`CalibratedClassifierCV`)
3. **Random Forest Classifier** with balanced class weighting

### Quantitative Benchmark Results

| Model | Evaluation A (Unseen Jobs Test Acc) | Evaluation A (Test Macro F1) | Evaluation B (Unseen Resumes Acc) | Evaluation B (Unseen Resumes Macro F1) | Model Status |
| :--- | :---: | :---: | :---: | :---: | :---: |
| **Logistic Regression** | **50.43%** | **0.4664** | **65.09%** | **0.6459** | **Selected Champion** |
| Linear SVC (Calibrated) | 51.39% | 0.3990 | 62.85% | 0.5642 | Candidate |
| Random Forest | 49.23% | 0.4274 | 65.87% | 0.6541 | Candidate |

> **Evaluation A**: Evaluates generalization to entirely novel, unseen job descriptions (held-out test split, $N=1,759$, 71 unseen jobs).  
> **Evaluation B**: Evaluates generalization to group-disjoint, unseen student resumes (`GroupShuffleSplit`, $N=1,292$, 0 overlapping resumes).  
> **Note on Probabilities**: Logistic Regression prediction scores are model-estimated probabilities generated by the softmax function; they have not undergone post-hoc calibration assessments.

### Feature Representation (2,518 Dimensions)
- **1,500 Unigram & Bigram TF-IDF features** (sublinear term frequency, English stopword removal)
- **1,000 Dimension Interaction Features** (Hadamard element-wise product & cosine similarity)
- **18 Dense Linguistic & Alignment Features**:
  - Exact skill overlap count and Jaccard similarity
  - Job skill coverage ratio and candidate resume skill density
  - Explicit candidate experience years and job-required experience gap
  - Structural metadata: section counts, word counts, character lengths

## Setup & Execution Guide (Windows 10/11)

### 1. Prerequisites
- Python 3.10 to 3.14 (Verified and tested on Python 3.14.8 64-bit on Windows)
- PowerShell or Command Prompt

### 2. Setup Virtual Environment
Open PowerShell or Command Prompt in the project root directory:

```powershell
# Create virtual environment
python -m venv venv

# Activate virtual environment (PowerShell)
.\venv\Scripts\Activate.ps1

# (Or Activate virtual environment in Command Prompt)
.\venv\Scripts\activate.bat
```

### 3. Install Dependencies
```powershell
pip install -r requirements.txt
```

### 4. Run the Full Test Suite
Verify that all 57 automated tests pass:
```powershell
python -m pytest -v tests/
```

### 5. Launch the Web Application
```powershell
python app.py
```
The server will start locally:
- **Application URL**: [http://127.0.0.1:5000](http://127.0.0.1:5000)
- **Health Check Endpoint**: [http://127.0.0.1:5000/health](http://127.0.0.1:5000/health)

## Core Application Views
1. **Interactive Resume Matcher (`/analyze`)**: Upload PDF, DOCX, or TXT resumes, or paste text directly. Select sample job descriptions or input custom targets.
2. **Analysis Results (`/results?id=...`)**: Displays overall predicted class, calibrated model confidence, breakdown of matched vs. missing skills, experience alignment, and actionable resume edits.
3. **Interactive Skill Gap Matrix (`/skill-gap`)**: Explores missing skills categorized by urgency (High, Medium, Low priority) with direct links to official documentation (e.g., Python.org, Docker Docs, Kubernetes.io).
4. **Supervised Model Performance (`/model-performance`)**: Inspects authentic confusion matrices, ROC/PR curves, classification reports, and cross-model comparison tables.
5. **Dataset Explorer (`/datasets`)**: Interactive view of the real Hugging Face training samples, skill distributions, and class frequencies.

## Edge Cases Handled & System Limitations

### Edge Cases Handled
- **Scanned PDFs**: Automatically detects PDFs lacking digital text layers and prompts the user to provide a digital document rather than failing silently.
- **Corrupted Files & Invalid Formats**: Traps and safely handles corrupted byte streams and unsupported file extensions (`.exe`, `.png`, `.bin`).
- **Punctuation-Sensitive Tokens**: Accurately preserves language keywords like `C++`, `C#`, `.NET`, `Node.js`, and `CI/CD` across cleaning, tokenizing, and matching.
- **Zero-Experience Candidates**: Calculates explicit gaps without inventing experience or failing on early-career resumes.
- **Session Security**: Analysis IDs are bound to user session cookies, preventing unauthorized cross-session access to uploaded candidate analyses.

### Limitations & Future Improvements
- **Optical Character Recognition (OCR)**: Scanned image-only PDFs currently prompt for a digital text copy. Integrating lightweight local Tesseract OCR is a future extension.
- **Context-Specific Experience**: The system deterministic extraction focuses on explicit stated years. Deep semantic tenure estimation from disjoint date ranges can be further refined.
- **Domain Specialization**: The skill lexicon consists of 4,476 technology and engineering skills; non-technical domains (e.g., culinary, healthcare) rely on broader TF-IDF similarity.
